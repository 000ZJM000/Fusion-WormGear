# 参数化蜗轮蜗杆生成器 (Worm & Worm Gear Generator) for Autodesk Fusion 360

依据 **GB/T 10085-2018**，在 Fusion 360 中一键生成参数化蜗杆与蜗轮实体，可选自动装配并建立传动运动链接。

## 功能特性

**几何计算 `worm_math.py`**
- 按国标计算模数 `m`、头数 `z1`、齿数 `z2`、直径系数 `q`、变位系数 `x2`、中心距 `a`、导程角 `γ`、齿厚与齿槽宽
- 两种配凑方式：按 `x2` 求 `a`，或按 `a` 反求 `x2`
- 校核：根切、变位后顶隙、法向侧隙、齿宽上限、长度下限、倒角上限、非有限值防护
- 力学输出：滑动速度、摩擦角、传动效率、自锁判定

**蜗杆建模 `worm_builder.py`**
- 纯圆柱蜗杆，**长度严格等于 `b1`**，两端无外伸轴颈，便于后续车削夹持与台阶轴加工
- 3D 分度圆路径 + 外圆导引轨双螺旋线扫掠，法向截面梯形刀具成型
- 支持多头蜗杆（`z1 ≥ 1`）环向阵列，可选齿顶螺旋棱边倒圆

**蜗轮建模 `gear_builder.py`**
- **纯实心喉圆轮坯**，无预制轴孔，便于按装配需要另行钻孔 / 镗孔 / 拉键槽
- 沿齿宽取 5 / 7 / 9 / 11 个平行截面，按啮合条件求解齿槽左右齿廓，实体放样成单齿槽后全周阵列切除
- 齿廓求解采用「全域粗扫描 + 二分细化」；无解时显式报错，不返回假齿廓

**交互与装配 `WormGearGenerator.py`**
- 原生参数面板，全中文标签 + 悬浮提示（含公式与取值范围）
- 实时校核报告；**校核不通过会中止生成并列出原因**，不会输出错误几何
- 装配体自动 90° 交错轴就位，建立原生旋转副 + 传动比运动链接

## 安装

无需把文件复制进 Fusion 安装目录，直接添加本文件夹即可。

### 添加为附加模块（推荐，可用常驻按钮）

1. 打开 Fusion 360，按 **`Shift + S`** 打开【脚本和附加模块】窗口
2. 切换到 **【附加模块】(Add-Ins)** 选项卡
3. 点击顶部绿色 **【+】** 按钮
4. 在文件浏览窗口中选中 **本文件夹**（即含 `WormGearGenerator.manifest` 的那一层），点击【选择文件夹】
5. 列表中会出现 `WormGearGenerator`，选中后点击右下角 **【运行】(Run)**
6. 参数面板会立即弹出。若想常驻工具栏，勾选底部 **"在启动时运行" (Run on Startup)**

> ⚠️ **文件夹名必须保持 `WormGearGenerator`**，且与 `WormGearGenerator.manifest` 同名 —— 这是 Fusion 识别附加模块的要求，重命名会导致无法加载。
>
> 因此建议**克隆 / 解压后直接使用本文件夹本身**，不要重命名，也不要只把里面的 `.py` 拷到别处。

### 使用方法

- **`Shift + S`** 打开窗口后运行，或
- 点击工具栏 **【实体】(Solid) → 【创建】(Create)** 面板中的 **【蜗轮蜗杆生成器】** 按钮

## 参数说明

| 参数 | 符号 | 说明 | 常用值 |
| :--- | :---: | :--- | :--- |
| 模数 | `m` | 轴向模数 `mx = m` | 1, 1.25, 1.6, 2, 2.5, 3.15, 4, 5, 6.3, 8, 10 mm |
| 蜗杆头数 | `z1` | 传动比 `i = z2 / z1` | 1, 2, 4（`z1 = 1` 自锁性最好） |
| 蜗轮齿数 | `z2` | 不得小于 17 | 28 ~ 80 |
| 直径系数 | `q` | `q = d1/m`，必须 > 2.4 | 8, 10, 12.5, 16, 20 |
| 压力角 | `α` | ZA 为轴向压力角、ZN 为法向压力角 | 20° |
| 变位系数 | `x2` | 凑配中心距 / 消除根切 | −0.5 ~ +0.5 |
| 中心距 | `a` | `a = 0.5·m·(q + z2 + 2·x2)` | 40, 50, 63, 80, 100, 125 mm |
| 蜗杆螺纹长度 | `b1` | 纯圆柱体长度，模型长度严格等于此值 | 自动推荐，可自定义 |
| 蜗轮齿宽 | `b2` | `z1 ≤ 2` 时 ≤ `0.75·da1` | 自动推荐，可自定义 |
| 法向侧隙 | `jn` | 各分配一半到蜗杆与蜗轮 | 0 ~ 0.1 mm |
| 齿面放样精度 | — | 蜗轮齿槽的放样截面数 | 高精（9 截面） |

### 齿形制式

- **ZA（阿基米德蜗杆）**：轴向截面为直线齿廓，轴向压力角为标准值 20°，国标最常用
- **ZN（法向直廓蜗杆）**：法向截面为直线齿廓，法向压力角为标准值 20°

两者均按**法向截面刀具沿螺旋线扫掠**成型，因此 ZN 为精确成型，ZA 为法向等效近似。

├── WormGearGenerator.py        # 主入口：命令面板、参数校核、装配与运动链接
├── WormGearGenerator.manifest  # Fusion 附加模块清单
├── worm_math.py                # GB/T 10085 几何与力学计算、参数校核
├── worm_builder.py             # 蜗杆：双螺旋线扫掠切削
├── gear_builder.py             # 蜗轮：多截面共轭齿廓放样 + 阵列切除

## 已知限制

- **ZA 齿形为法向等效近似**：蜗杆按法向截面直线梯形沿螺旋线扫掠成型。对 ZN 是精确成型；对 ZA（要求轴向截面为直线）是工程近似。
- **离开中截面后左右齿面不再严格镜像**：螺旋面本身具有手性，只有在中截面（`zk = 0`）上两侧才严格镜像，离开中截面后存在随 `|zk|` 增大的方位差。这是螺旋齿轮的固有特性，非建模缺陷。
- **齿数较多时生成较慢**：蜗轮齿槽的全周阵列差集耗时随 `z2` 增长，过程中无进度提示。`z2` 接近 120 时建议先用「快速（5 截面）」试算。
- **需要 Design 建模环境**，且仅支持 Windows / macOS 上的 Fusion 360。

## 贡献

欢迎提交 Issue 与 Pull Request。

修改几何或装配相关代码时，请先运行 `python test_math.py`。特别提醒两处容易踩坑的地方：

1. **装配变换矩阵**（`WormGearGenerator.py` 中 `ax` / `ay` / `az` 三个向量）：必须单位正交、构成右手系（`ax × ay = az`）、行列式 `+1`，且第三个向量（蜗杆自身轴线）为全局 `+Y`。写成反射矩阵会被 Fusion 以 `invalid argument transform` 拒绝。
2. **运动链接符号**（`ml_input.isReversed`）：蜗杆轴为 `+Y`、蜗轮轴为 `+Z`，两者轴线不同，转向符号由啮合几何决定，不能凭直觉取。改动装配姿态后此处必须一并校准。
