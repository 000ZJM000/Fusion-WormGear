# 参数化蜗轮蜗杆生成器 (Worm & Worm Gear Generator) for Autodesk Fusion 360

依据国家标准 **GB/T 10085-2018** 与 **GB/T 10087-2018**，在 Autodesk Fusion 360 中一键参数化生成高精度蜗杆与蜗轮实体模型，支持自动 90° 空间交错装配、原生旋转副（Revolute Joint）与传动运动链接（Motion Link）。

## 核心功能与技术亮点

1. **国标几何与力学精准计算 (`worm_math.py`)**
   - 严格遵循 GB/T 10085-2018 标准，计算模数 $m$、头数 $z_1$、齿数 $z_2$、直径系数 $q$、变位系数 $x_2$、中心距 $a$、导程角 $\gamma$、齿厚与齿槽宽；
   - 支持两种配凑模式：**「由变位系数 $x_2$ 计算中心距 $a$」** 与 **「由指定中心距 $a$ 反求变位系数 $x_2$」**；
   - 内置工程级防呆校核：根切校核、变位后顶隙余量干涉预警、法向齿侧间隙 $j_n$ 分配、齿宽上限、螺纹长度下限、倒角上限与非有限值过滤；
   - 依据 ISO/TS 14521 提供滑动速度、动静摩擦角、正向传动效率 $\eta$ 与自锁状态等级判定（完全自锁/静态自锁/临界自锁/可逆转）。

2. **纯圆柱蜗杆实体建模 (`worm_builder.py`)**
   - **纯圆柱无外伸轴颈**：模型长度严格等于 $b_1$，便于后续自由安排车削夹持、台阶轴加工、键槽与数控编程；
   - **双螺旋线扫掠成型**：3D 分度圆路径 + 外圆导引轨，消除空间挠率扭转，法向截面梯形刀具高精度切削；
   - 支持多头蜗杆（$z_1 = 1 \sim 6$）环向阵列，两端自动切平，可选齿顶螺旋棱边倒圆。

3. **蜗轮多截面共轭齿廓放样 (`gear_builder.py`)**
   - **纯实心喉圆轮坯**：无预制内轴孔，便于按装配需要精确钻孔、镗孔或拉键槽；
   - 沿齿宽取 5 / 7 / 9 / 11 个平行截面，按理论共轭啮合条件数值求解齿槽左右齿廓，实体放样成单齿槽后全周阵列差集切除 $z_2$ 个齿槽；
   - 齿廓求解采用「全域粗扫描 + 二分细化」，根绝假齿廓与退化；
   - **全工况自适应轮坯边界**：对窄齿宽蜗轮（$b_2/2 \le z_{\text{int}}$）与标准宽轮分别进行几何闭合与连续倒角，彻底消除边缘未切除的片状薄片残留。

4. **装配姿态与多头自转相位严密对准 (`worm_phase.py`)**
   - 基准装配矩阵严密保证局部自身轴线正交对准全局 $+Y$，实心螺纹齿顶中心线精确朝向全局 $-X$（正对蜗轮齿槽对称中心）；
   - 多头蜗杆相位角 $\psi = (180^\circ - \theta_{\text{tooth}}) \pmod{360^\circ}$ 精准匹配，确保齿顶正向进入齿槽，杜绝顶碰干涉；
   - 自动适应 Fusion 360 设计文档类别（装配设计建立原生旋转副；零件设计模式直接应用三维变换矩阵准确就位）。

5. **原生参数化交互面板与智能联动 (`WormGearGenerator.py`)**
   - 原生 CommandDialog 界面，全中文标签与丰富悬浮帮助提示；
   - 参数动态联动：修改模数/齿数/变位时，蜗杆长度 $b_1$ 与齿宽 $b_2$ 自动刷新国标推荐值；
   - 实时 HTML 摘要：即时显示传动比、中心距、导程角、理论效率、自锁性与错误警告；
   - 生成前强制校核拦截，杜绝异常参数输出错误实体。

## 安装与快速启动

本插件支持「脚本 (Scripts)」与「附加模块 (Add-Ins)」双模式部署，**无需向系统盘复制文件**，直接添加本文件夹即可：

### 方式一：在【脚本和附加模块】窗口直接运行
1. 在 Fusion 360 中按快捷键 **`Shift + S`** 打开窗口；
2. 切换到 **【附加模块】(Add-Ins)** 或 **【脚本】(Scripts)** 选项卡；
3. 点击顶部的绿色 **【+】** 加号按钮；
4. 在弹出的文件浏览窗口中选中本插件文件夹（含 `WormGearGenerator.manifest` 的层级），点击【选择文件夹】；
5. 列表中出现 **`WormGearGenerator`**，选中后点击右下角 **【运行】(Run)** 即可呼出参数面板。

### 方式二：常驻顶部工具栏按钮（推荐）
1. 在【附加模块】选项卡中选中 `WormGearGenerator`，勾选底部的 **“在启动时运行” (Run on Startup)**，然后点击 **【运行】**；
2. 切换至顶部工具栏 **【实体】(Solid) → 【创建】(Create)** 面板，即可看到常驻的 **【蜗轮蜗杆生成器】** 专属图标按钮。

> ⚠️ **注意**：文件夹名请保持为 `WormGearGenerator`，且与清单文件 `WormGearGenerator.manifest` 同名，以确保 Fusion 360 正确识别插件包。

## 核心参数对照表 (GB/T 10085-2018)

| 参数名称 | 符号 | 常用推荐值 | 说明 |
| :--- | :---: | :---: | :--- |
| **生成模式** | - | 完整装配体 / 仅蜗杆 / 仅蜗轮 | 装配体将建立交错就位与旋转传动副 |
| **齿形制式** | - | ZA (阿基米德) / ZN (法向直廓) | ZA 为轴向标准 20°（最常用）；ZN 为法向标准 20° |
| **螺旋旋向** | - | 右旋 (常用) / 左旋 | 决定齿槽空间倾斜方向与运动链接传动转向 |
| **齿面放样精度** | - | 高精 (9 截面) / 超精 (11 截面) / 标准 (7 截面) / 快速 (5 截面) | 放样截面数越多齿面越光顺，耗时相应增加 |
| **模数** | $m$ | 1.0, 1.25, 1.6, 2.0, 2.5, 3.15, 4.0, 5.0, 6.0 等 | 决定齿轮抗弯强度与主尺度 ($m_x = m$) |
| **蜗杆头数** | $z_1$ | 1, 2, 3, 4, 6 | 传动比 $i = z_2 / z_1$；$z_1 = 1$ 自锁性能优异 |
| **蜗轮齿数** | $z_2$ | 28 ~ 80 (最小不小于 17) | 齿数过少易产生根切，建议配合正变位使用 |
| **直径系数** | $q$ | 8.0, 10.0, 12.5, 16.0, 20.0 等 | $q = d_1 / m$，必须 $> 2.4$；越大刚度越好但导程角越小 |
| **配凑方式** | - | 按变位系数求中心距 / 按指定中心距反求变位 | 适合自由设计或凑配已有标准中心距箱体 |
| **变位系数** | $x_2$ | $-0.5 \sim +0.5$ | 凑配中心距 $a$ 或消除根切；过大时会提示顶隙余量 |
| **中心距** | $a$ | 40, 50, 63, 80, 100, 120, 125 mm 等 | 优先中心距标准系列：$a = 0.5m(q + z_2 + 2x_2)$ |
| **蜗杆螺纹长度** | $b_1$ | 纯圆柱体长度，严格等于此值 | 满足 $b_1 \ge (11 + 0.06 z_2) m$ 且完全覆盖喉部啮合弦长 |
| **蜗轮齿宽** | $b_2$ | 纯实心轮坯外宽 | $z_1 \le 2$ 时 $\le 0.75 d_{a1}$；$z_1 = 3$ 时 $\le 0.70 d_{a1}$ |
| **法向侧隙** | $j_n$ | 0 ~ 0.1 mm | 制造侧隙：向蜗杆与蜗轮各分配一半，便于装配与油膜润滑 |
| **蜗轮端面倒斜角** | $c$ | 默认取齿宽的 5% | 喉部圆弧两侧端面的倒角特征，必须小于 $b_2 / 2$ |
| **蜗杆齿顶倒圆** | $r$ | 0 ~ 0.35m | 蜗杆齿顶螺旋棱边的倒圆角（0 为尖锐齿顶） |

## 文档类别与生成策略说明

Fusion 360 存在不同的文档环境，对多零部件的支持策略如下：

| 检测到的文档类别 | 支持多零部件 | 插件处理策略 |
| :--- | :---: | :--- |
| **装配设计 (Assembly)** | ✅ 支持 | 自动新建「蜗轮」与「蜗杆」独立子零部件，建立 90° 空间旋转副与啮合传动比运动链接 |
| **零件设计 (Part)** | ❌ 仅限单件 | 自动降级为根组件实体模式，两件实体严格按中心距与装配矩阵就位，弹出友好提示 |
| **混合设计 (Hybrid)** | ✅ 支持 | 兼容多零部件与装配绑定 |

> **提示**：若需要可拖动旋转的装配副与运动动画，请在空白文档中直接运行；若在零件设计文档中运行，两零件也会精准放置在正确空间装配坐标处。

## 自动化单元测试验证

本工程附带完整的无需外部依赖的 Python 单元测试套件：

```bash
python test_math.py
```

执行后将运行全部 53 项自动化测试（耗时约 3~4 秒）：
- **几何与力学测试 (`TestWormGearMath`)**：国标标准组合、自锁判定阈值、中心距与变位互求闭合性、特征半径恒等式；
- **边界参数安全校核 (`TestValidation`)**：$b_1$ 最小长度、$b_2$ 上限、倒角上限、侧隙过大、非有限值（NaN/Inf）拦截、顶隙干涉预警；
- **共轭齿廓求解测试 (`TestConjugateSectionCurves`)**：齿廓单调性、对称性、多截面求解有效性、边界夹断防护；
- **装配基底与手性测试 (`TestAssemblyFrame`, `TestSlotHandedness`)**：矩阵单位正交性、右手系、行列式 $+1$、三列基向量物理指向、左/右旋齿槽斜率与运动链接反向标志；
- **设计文档自适应测试 (`TestDocIntent`)**：意图枚举提取、策略分派与安全容错。

```
WormGearGenerator/
├── WormGearGenerator.py        # 插件主入口：命令面板、参数联动、装配副与运动链接

├── worm_phase.py               # 蜗杆装配基底姿态与多头自转相位角精准计算

├── test_math.py                # 53 项单元测试套件（无需 Fusion 环境即可运行）
├── make_icons.py               # 图标生成辅助脚本
├── README.md                   # 详细使用说明文档
└── LICENSE                     # MIT 开源许可证
```
